# Google Play Listing Assets

1. `app-icon-512.png`: 512 by 512 pixel RGBA Play Store icon rasterized from the app's existing adaptive launcher artwork.
2. `feature-graphic-1024x500.png`: 1024 by 500 pixel RGB feature graphic for the Main store listing.
3. `phone-active-timer.png`: recommended first screenshot showing a running 15-minute restore timer.
4. `phone-silent-prompt.png`: recommended second screenshot showing the timer prompt and presets.
5. `phone-monitoring.png`: recommended third screenshot showing monitoring enabled and all permissions granted.
6. `phone-main.png`: optional onboarding screenshot showing the required permission controls.

All phone screenshots are 1080 by 2160 pixel RGB PNGs captured from the release APK on an API 36 emulator. They contain no personal device content and comply with Google Play's 2:1 maximum aspect ratio.

The foreground-service review video is a separate policy artifact and should not be uploaded as the optional marketing preview video unless it is also suitable for public display.
